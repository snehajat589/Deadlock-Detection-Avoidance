Deadlock Detection and Avoidance Simulator

📌 Project Overview

The Deadlock Detection and Avoidance Simulator is an Operating System project developed using Python.

This project implements the Banker's Algorithm to check whether a system is in a safe or unsafe state. It helps understand how operating systems allocate resources and prevent deadlocks.

🎯 Objectives

- Understand the concept of deadlocks in Operating Systems.
- Implement Banker's Algorithm using Python.
- Calculate the Need Matrix.
- Check system safety.
- Identify a safe sequence of processes.
- Detect unsafe system states.

🛠️ Technologies Used

- Python
- Jupyter Notebook / Google Colab
- Banker's Algorithm

⚙️ Features

1. Accepts process and resource information.
2. Uses Allocation and Maximum matrices.
3. Calculates the Need Matrix.
4. Checks available resources.
5. Finds a safe sequence if one exists.
6. Identifies safe and unsafe states.
7. Displays the execution results.

🧠 Algorithm Used

Banker's Algorithm

Banker's Algorithm is a deadlock avoidance algorithm used by operating systems to ensure that resource allocation does not lead to an unsafe state.

Important Formula

Need = Maximum - Allocation

🚀 How to Run

1. Download or clone this repository.
2. Open "Deadlock_Simulator.ipynb".
3. Run the notebook in Jupyter Notebook or Google Colab.
4. Execute the cells step by step.
5. Observe the Need Matrix and safety algorithm results.

📊 Expected Output

- Allocation Matrix
- Maximum Matrix
- Available Resources
- Need Matrix
- Safe Sequence
- System Safe / Unsafe Status
